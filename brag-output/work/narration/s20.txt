Seventeen percent is a long way from the one percent goal, so the model does not block by default. The gateway runs in enforce L one mode. When an operator is ready, machine-learning blocking can be switched on per endpoint, for a small canary of clients, behind an automatic brake. If the would-block rate passes five percent, the brake turns machine-learning blocking off by itself, while layer one keeps blocking. And a single client can never trip it alone, so an attacker cannot switch the model off with volume.
