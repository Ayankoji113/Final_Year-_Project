Layer one is twenty-six deterministic signatures, covering S.Q.L. injection, cross-site scripting, path traversal, command injection, server-side request forgery, scanner probes, and deserialization. Every rule is either block, or flag. A pattern only earns block if a legitimate client would essentially never send it, like union select. Weaker patterns become flags: evidence for the model, not an instant four oh three. And rules match structure, not single characters, so a customer named O'Brien goes straight through.
